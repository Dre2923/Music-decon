# Core Loop

Intent router and the LISTEN → DIAGNOSE → EXPLAIN → SHOW → PRACTICE → VERIFY → SAVE orchestrator, plus the lesson/practice engine and saved-progress model. See manifesto Section 1.

**Status:** not yet implemented.

Key rule from the manifesto this module must honor:
- VERIFY is not optional narration. Where technically possible, the loop listens again after guidance is given and determines whether the user actually corrected the issue, rather than just telling them what was wrong once.
